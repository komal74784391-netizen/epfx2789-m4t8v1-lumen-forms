# Lumen Form Engine

**Status:** Released · v1.3.2 · 2026-05-18

Declarative form schema engine used by the Lumen input components.

## Install

```bash
pip install lumen-forms
```

## What is in this repository

- `src/lumen_forms/schema.py` — schema model and validation dispatch
- `src/lumen_forms/validators.py` — async validator adapters
- `tests/test_schema.py` — schema regression tests
